# Changelog

## 0.1.1 (2026-10-15)

Released from [MarkNygaard/niles-bambulab](https://github.com/MarkNygaard/niles-bambulab) as `v0.1.1`.

### Features

* Bambu Lab's own logo.
* When a printer in cloud mode refuses pause, resume or stop, Niles says so plainly, and the page and the assistant stop offering them until you try again.

## 0.1.0 (2026-10-15)

The first release, from [MarkNygaard/niles-bambulab](https://github.com/MarkNygaard/niles-bambulab) as `v0.1.0`: the printer and its chamber light as devices, tools to follow, pause, resume and stop a print, the "3D printer" page and card, and announcements when a print finishes or fails.
